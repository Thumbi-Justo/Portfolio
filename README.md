# Justus Portfolio Website

A responsive portfolio website built with separate HTML, CSS, and JavaScript files.

## Files
- `index.html` — website content and sections
- `style.css` — layout, colors, responsive styling, and effects
- `script.js` — mobile navigation, current year, and WhatsApp contact link

## Run locally
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Before publishing
1. In `script.js`, replace `YOUR_WHATSAPP_NUMBER` with your WhatsApp number in international format using digits only (including the country code, without `+`, spaces, or punctuation).
2. In `index.html`, update your contact details and add your GitHub, LinkedIn, and project links.
3. Replace project concept previews with screenshots of your actual work when available.
4. Keep skills and project descriptions accurate to what you can explain in an interview.
5. Add a downloadable CV link only after you have a finalized CV.

## Publish for free
You can upload the three website files to a GitHub repository and enable GitHub Pages, or deploy the folder using Netlify. Use the final public URL in your CV and job applications.
